# tfetch
A simple fetch program written in Python (dw its not too slow)
# Install
- Create a venv with `python -m venv .venv`
- Activate the virtual environment with `source .venv/bin/activate`
- Install the needed libraries, `pip install distro && pip install psutil && pip install pyinstaller`
- Build with `pyinstaller --onefile --name "tfetch" main.py`
