# tfetch
My own fetch program written in Rust. Short for "Tubular-Fetch". Features pride flags and an ASCII bunny. Only configurable and customizable through the source code. Feel free to request new flags or changes.

# Installation
- Make sure to have Cargo and Rust installed
- Run `cargo build -r` from within the folder containing everything
- Run `sudo mv [path to the binary] /usr/local/bin/`
